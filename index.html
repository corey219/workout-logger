How this works

Each set: enter weight × reps × RIR (reps in reserve at end of set). The "Est 1RM" column updates live using Epley + RIR adjustment: 1RM = w × (1 + (reps + RIR) / 30).

Rest period is shown in the lift header (blue pill). Tap "Start Rest" after a set — a global countdown timer appears at the bottom of the screen, beeps + vibrates when done.

Banded exercises (face pulls, pull-aparts) ask for band color instead of weight. No 1RM is computed for bands — band tension varies through ROM and isn't well-modeled by 1RM math. Just track color + reps + RIR.

Save to Wiki writes the current workout into wiki/analysis-workout-log-2026-04.md through the local save bridge. If the same date + workout already exists, it updates that entry instead of duplicating it.

Lift 1RM shown in the header is the highest 1RM-equivalent across your logged sets for that lift this session — that becomes the new estimate (free-weight lifts only).

Storage: data persists in your browser localStorage. Reset clears the current session only. 1RM estimates persist across sessions.
